# SQA Day 7 – Mini QA Test Project
## 📌 Project Overview
This project was completed as part of the SQA Internship Day 7 task.
The objective of this project was to perform a complete QA testing cycle on the publicly available DemoBlaze web application.
The testing was performed from a QA Engineer's perspective, covering functional, UI, validation, usability, API, boundary, positive, negative, and cross-browser testing.
## 🌐 Application Under Test
**Application:** DemoBlaze  
**Type:** Public E-Commerce Web Application
## 🎯 Testing Areas
The following testing types were performed:
- Functional Testing
- UI Testing
- Form Validation
- Positive Testing
- Negative Testing
- Boundary Testing
- API Testing
- Usability Testing
- Cross-Browser Testing
## 📊 Test Coverage
The project includes:
- 50+ Web Test Cases
- Positive Test Cases
- Negative Test Cases
- Boundary/Validation Test Cases
- API Test Cases
- Bug Reports
- Usability Testing
- Cross-Browser Testing
- Screenshots/Evidence
## 🔌 API Testing
API testing was performed using **Postman**.
The API testing covered:
- GET Requests
- POST Requests
- Product APIs
- Category APIs
- Product Details
- Add to Cart
- Negative API Testing
- Response Validation
- Authentication Testing
The Postman collection is available in the `API-Testing` folder.
## 🐞 Bug Reporting
